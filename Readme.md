# 🍅 Tomato AI Support Chatbot

An AI-powered customer support chatbot built using **Node.js, Express.js, and Google's Gemini API**. This project was developed as part of my learning journey into **Forward-Deployed Engineering (FDE)**.

Tomato AI Support is designed to answer customer queries related to food orders, delivery, payments, refunds, cancellations, and restaurant support.

## 🚀 Features

- **AI-Powered Responses:** Uses Google's Gemini API to generate responses to customer queries.
- **Context-Aware Conversations:** Maintains conversation history to support follow-up questions.
- **System Instructions:** Guides the AI to focus on food-ordering and restaurant-support topics.
- **REST API:** Connects the frontend to the AI-powered backend through Express.js.
- **Interactive Chat Interface:** Allows users to send messages and view responses in the browser.
- **Enter-Key Support:** Send messages by pressing Enter.
- **Clear Chat:** Clears the displayed chat and resets the server-side conversation history.
- **Input Validation:** Rejects empty messages and messages exceeding the configured length limit.
- **Error Handling:** Handles API errors and returns appropriate error responses.

## ⚙️ Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- A Google Gemini API key from [Google AI Studio](https://aistudio.google.com/)

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd chatbot
```

### 2. Install dependencies

```bash
npm install
```

Ensure your project includes these dependencies:

```bash
npm install express dotenv @google/genai
```

### 3. Configure environment variables

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Replace the placeholder with your own API key.

**Important:** Never commit your `.env` file or expose your API key publicly.

### 4. Start the server

```bash
node server.js
```

The server should start at:

```text
http://localhost:3000
```

### 5. Open the chatbot

Open the following URL in your browser:

```text
http://localhost:3000
```

You can now send messages to Tomato AI Support.

## 🔌 API Endpoints

### `GET /`

Serves the chatbot frontend when Express static-file middleware is configured for the `public` directory.

### `POST /chat`

Accepts a plain-text message and returns the AI-generated response.

**Request header:**

```text
Content-Type: text/plain
```

**Request body:**

```text
Where is my order?
```

**Response:** Plain-text response generated by Gemini.

### `POST /reset`

Clears the in-memory conversation history and returns a confirmation message.

## 🧠 How It Works

1. The user enters a message in the browser.
2. The frontend sends the message to the Express backend.
3. The backend adds the user's message to the conversation history.
4. The Gemini API generates a response using the conversation history and system instructions.
5. The model's response is added to the conversation history.
6. The backend sends the response to the frontend.
7. The frontend displays the conversation.
8. The reset endpoint clears the conversation history when requested.
